## Review Focus

1. Same value in a visible link, its href, two translated attributes, a nested child target or protected code/SVG: validate its actual owned location, not all serialized text or a permissive total. Task1 tests pin unchanged acceptance and location-specific tampering rejection.
2. `MUST` alongside `MUST NOT`, `SHALL NOT`, `SHOULD NOT`, `NOT RECOMMENDED`, mixed keyword/identifier values and punctuation boundaries: no overlapping double count, no loss/negation/duplicate/suffix acceptance. Task1 pins both directions.
3. Existing/multiple charset or content-type metadata and head targets surrounding the inserted CSP: map only the assembler's known normalization, never hide arbitrary reordered, absent or duplicate targets. Task1 checks real assembly and malicious variants.
4. CSP text is not enforcement: absent, report-only, misplaced/late, malformed, duplicate-first-wins or script-src-elem overrides must not grant a preload exemption. Task1 parameterized static and real-browser cases pin conservative classification.
5. A link mixing stylesheet/modulepreload, preload-as-style, CSS imports/unsupported URLs, external base, unavailable critical CSS and optional font/icon resources retain their existing classifications. Task1 tests coexistence with script blocking.
