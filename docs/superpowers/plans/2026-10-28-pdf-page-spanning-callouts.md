# Page-spanning PDF Callouts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve uniquely proven page-spanning text callouts as selectable, logically translated and reflowable Korean content, then resume the requested whole PDF only after code/native gates pass.

**Architecture:** Detect a document-level chain before table/figure ownership; persist exact source membership in a versioned document extension. Reuse the existing paragraph/list projection and renderer, scoped by explicit group identity, and revalidate source/group/output evidence through held-input publication consumers. Non-callout native documents retain their existing serialized formats.

**Tech Stack:** Python 3.11+, pdfplumber/pdfminer, pypdf, ReportLab, Pillow/Poppler, pytest and existing macOS/Windows Actions. No new dependency or translation service.

**Spec:** `docs/superpowers/specs/2026-10-27-pdf-page-spanning-callouts-design.md` (detailed design approved by the user's subsequent “네”, 2026-10-28).

## Global Constraints

- Their text must remain selectable and AI-translated, not become a preserved illustration. Source artwork remains original pixels; independent tables, captions, code, references and surrounding body retain their existing ownership and protection.
- Preserve one title, separate complete paragraphs and list items. Join only a paragraph or list item actually continued over a source page boundary; never translate the whole box as one undifferentiated target.
- No page/title/phrase/font allowlists, OCR, machine translation, source edits, synthetic closing borders as source evidence, automatic semantic passes, weakened figure exceptions, lowered limits or old approval reuse. Limits stay 500 input pages and 50 MiB.
- Initially support actual axis-aligned straight source borders, including equivalent line/path encodings. Rounded/nested/irregular containers and artwork embedded in a newly detected open-border chain are not newly enabled. Existing supported single-page callout/icon cases must not regress.
- Whole glyph ownership, peer overlap, table/figure exclusion and source character accounting remain mandatory. Punctuation, lowercase text, a repeated title or style similarity alone proves neither continuation nor separation. Ambiguous ownership/flow remains a required blocker.

## Review Focus

1. Mirrored margins, actual nonzero page origins and rotation must not confuse source coordinates or connect unrelated boxes: Tasks 2/3, `test_callout_chain_native_geometry_matrix` and `test_callout_source_projection_matches_extraction`.
2. One-line edge fragments, separate finished paragraphs and hanging lists must not be silently split or merged: Task 4, `test_callout_boundary_preserves_paragraph_and_item_identity`.
3. Footer/header text or a broken mid-page frame must not manufacture page-edge evidence: Task 2, `test_callout_edge_proof_excludes_furniture_and_external_prose`.
4. A copied/rebound group, including changed glyph membership with renewed outer hashes, must independently fail source validation: Task 6, `test_callout_publication_refuses_rebound_foreign_group`.
5. A long Korean box and links/notes into its continued units must retain one title/marker/translation and correct anchors without blank-page loops: Task 5, `test_linked_callout_reflow_preserves_units_and_anchors`.
