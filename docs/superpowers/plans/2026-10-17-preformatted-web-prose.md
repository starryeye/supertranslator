## Review Focus

1. A plausible prose paragraph incorrectly declared literal can silently disappear from translation. Complete classification coverage plus master evidence must prevent false semantic approval; unknown/missing/mixed blocks fail closed (Tasks1,5).
2. Inline anchors or a wrapped URL crossing a block/package boundary can lose IDs, link text or protected characters. Preserve original order/IDs/attributes, keep URL spans literal, reject unsafe boundaries, and test decoded entities (Tasks1,2,4).
3. Source/review/derived/CSS/segments can change between validation, publication and QA. Verify held identities and hashes at every boundary; a matching derived DOM alone is insufficient (Tasks3,4).
4. CJK text and narrow viewports can destroy fixed-width grids or force whole-page overflow. Scope prose reflow CSS; keep literal islands exact and independently scrollable, including source page-furniture interruptions (Tasks2,4,5).
5. Legacy pages/PDF workflows and installed wheel resources can break even when source-tree fixtures pass. No mandatory new artifact for legacy runs; verify installed CSS, unchanged record/manifest shapes and both native OS jobs (Tasks4,5).

## File and contract map

- `src/web_translator/preformatted_contract.py`: strict versioned records, JSON decoding/validation and canonical hashes; no filesystem mutation or AI calls.
- `src/web_translator/preformatted_analysis.py`: deterministic DOM/line inventory and bounded package construction; no semantic approval.
- `src/web_translator/preformatted_projection.py`: validated symbolic decisions to deterministic flow/literal DOM and mapping; no AI-authored markup.
- `src/web_translator/preformatted_runtime.py`: held-run lifecycle, transactions, source selection and provenance/literal verification; reuse `pdf_assemble`'s existing anchored primitives without modifying PDF behavior.
- `src/web_translator/web_assets/preformatted-flow.css`: only generated-container styles; packaged through `pyproject.toml`.
- Existing `cli.py`, `models.py`, `qa.py`, `report.py`: one coordinated integration task, not independent concurrent edits. Existing low-level `extract.py`, `protection.py` and `assemble.py` contracts need no exclusion removal or separate translation path.
- New focused tests: `test_preformatted_analysis.py`, `test_preformatted_projection.py`, `test_preformatted_runtime.py`, `test_preformatted_pipeline.py`; extend existing CLI/report/packaging tests only for real consumer behavior. Existing fixtures/expected outputs stay unchanged.

Run layout: keep raw `source.html`, `capture.json`, captured `assets/*` exact. `preformatted/analysis.json` and `preformatted/packages/package-NNNNNN.json` are immutable. Master writes `preformatted/review.json` before projection; backend then locks its hash in `preformatted/provenance.json`. `preformatted-source.html` lives at the run root so existing relative assets and assembly copying retain their base. Backend-generated CSS is `assets/wt-preformatted-<first16-sha256>.css`, separately bound as a generated critical asset, not claimed as captured. Existing artifact allocator roots and safe lexical paths remain authoritative.

Internal JSON schema version is `"1.0"` with exact keys; reject unknown keys, duplicate JSON keys, invalid Unicode/NaN, bool-as-integer offsets, unsafe paths and reserved-marker collisions. Record the source's parsed-DOM text once; offsets are Unicode codepoints in that stream, never bytes or a newly normalized string. Stable source/pre/line/block IDs are ordinal, independent of document words or URL.

Shared types are immutable dataclasses in `preformatted_contract.py`: Task1 owns `PreformattedAnalysis`, `ClassificationPackage`, `ReviewedBlocks`; Task2 adds `ProjectionArtifact`, `NormalizationSummary`; Task3 adds `ProjectionRecord`. Each producer owns its strict `from_dict`/`to_dict` validation and carries the concrete serialized field contract in its handoff report. Analysis retains all line text/separators, node paths/offsets, original ID/attribute mapping, explicit code constraints and package identities. Review records exact analysis/source hashes, `blocks`, and sorted `unresolved_required`; each block has `id`, `pre_id`, ordered contiguous `line_ids`, closed `role`, evidence, role metadata and optional source-bound literal spans. Use exactly the spec's ten roles. Unknowns or a nonempty unresolved list cannot project.

Wire-record ownership is exact: analysis has `schema_version,source_sha256,roots,lines,constraints,package_ids`; a package has `schema_version,id,analysis_sha256,target_lines,context_before,context_after`; review has `schema_version,source_sha256,analysis_sha256,package_sha256,blocks,unresolved_required`. `package_ids` contains names, not package hashes, avoiding a circular analysis/package digest. Review's `package_sha256` exactly maps every generated package ID to its canonical-byte digest. Analysis roots retain original DOM path/attributes/IDs; line records retain pre ID, ordinal line ID, decoded text, exact separator and source-node slices. Source-node offsets are codepoints in the recorded parsed stream; node paths enumerate all child nodes, not tag-only siblings.

The backend's reserved attributes are `data-wt-preformatted-root`, `data-wt-preformatted-block`, `data-wt-preformatted-literal`, `data-wt-preformatted-url`, `data-wt-preformatted-marker`; source attributes or source CSS claiming these selectors fail before annotation. Existing `data-wt-segment`/location-marker collision checks remain unchanged. Analysis inventories explicit code roots as preservation constraints even when excluded from eligible prose roots; projection verifies those retained islands too.

Heading metadata is an integer level1..6; list-item metadata supplies a nonnegative depth and a source-bound original marker span; caption metadata supplies an adjacent diagram/table block ID when grouping into a figure. Reject impossible hierarchy, invented markers/associations or unsupported nesting rather than guessing. Preserve list-marker characters as opaque inline content; do not generate a second numeric/bullet label. Wrapped URL spans use source line/column endpoints and exact source hashes; AI cannot supply a replacement address. Role-inapplicable metadata must be absent, not arbitrary ignored keys.

Packages contain at most12,000 target text characters and200 target lines; read-only context is at most two neighboring lines per side, each excerpt at most256 characters with an explicit excerpt flag. Coverage counts targets only. A single physical line or proposed translatable block exceeding the existing12,000-character unit budget fails explicitly; no truncation, unbounded prompt or silent literal reclassification. A block may cross a package boundary, not an intervening page-furniture island or pre root. These are bounded-processing limits, not document-page limits.
